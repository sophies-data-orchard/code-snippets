# Data Science & Analytics Portfolio

Welcome to my Data Science & Analytics portfolio.

This repository contains projects completed through graduate-level study, independent research, and personal exploration in analytics, machine learning, natural language processing, and generative AI.

Together, these projects represent a progression of technical skills—from statistical analysis and predictive modeling, through machine learning and customer analytics, to modern AI applications such as transformer models, Retrieval-Augmented Generation (RAG), and LLM-powered workflows. While each project addresses a different business problem, they share the same objective: applying data-driven methods to generate meaningful insights and practical solutions.

## Approach

Across these projects, I emphasize:

- Understanding the business problem before selecting analytical methods
- Building reproducible and well-documented workflows
- Applying appropriate statistical and machine learning techniques
- Evaluating results using transparent and rigorous methodologies
- Communicating findings through interpretable analyses and actionable recommendations

Several projects also document unsuccessful experiments, debugging processes, and iterative improvements to evaluation methods. These are intentionally preserved because they reflect how real analytical work evolves—from initial hypotheses to validated conclusions.
